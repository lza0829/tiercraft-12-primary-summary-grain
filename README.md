# 05-tiercraft（筑层）

筑层 — 数仓分层建设台：贴源入仓 → 明细清洗标准化 → 汇总落表 → 层间行数/键对账。

**不是** 多源 Feed 归并，**不是** 作业依赖编排，**不是** CDC 变更流按序落库，**不是** 质检隔离签发。
**也不是** 报表看板 / CRUD 后台 / 电商订单前台 / OA 工单。

## 启动

```bash
docker compose up --build
```

本地开发：

```bash
# 后端
cd backend
pip install -r requirements.txt
set DATA_DIR=..\data
uvicorn app.main:app --reload --port 10500

# 前端
cd frontend
npm install
npm run dev
```

| 入口 | 地址 |
| --- | --- |
| 前端 | http://localhost:5500 |
| 接口 | http://localhost:10500 |

## 主链

登记主题域 → 贴源层装载夹具 → 明细层清洗标准化 → 主汇总层聚合 → 层间对账报告与各层列表数字同源

## 主汇总与品类旁路（失败域隔离）

- **主汇总层（`layer_summary`）**：粒度锁定为业务日+门店编码，不含品类维，是层间对账唯一的汇总来源。
- **品类旁路（`layer_summary_category`）**：粒度为业务日+门店编码+品类，由独立旁路任务写入独立旁路表；不写主汇总层，不参与对账。
- **失败隔离**：旁路任务使用独立连接/事务，失败只回滚旁路表并落一条「品类旁路·失败」任务（含原因），不回滚、不清空、不锁死已成功的主汇总；主汇总成功而旁路失败时，对账仍只核主汇总与明细并可判定一致。
- **界面区分**：主路径与品类旁路在任务、分层、总览页面用通道标签区分；旁路计数只来自旁路表，不写入主汇总报告字段。
